# ForestScope — 現場データモード

ForestScope 3D森林ダッシュボードの現場一次データ収集機能です。

## 機能

### 📸 写真アップロードとAI判定
- スマホカメラから直接写真を撮影してアップロード
- EXIF GPS情報を自動抽出
- GPS情報がない場合は3D地球上をクリックして位置を指定
- **Pl@ntNet API** で植物の種同定（上位3候補）
- **iNaturalist Computer Vision API** で動物・鳥・昆虫も判定
- APIが利用できない場合は手動入力でも使用可能

### 💾 ローカル保存（IndexedDB）
- すべてのデータはブラウザ内のIndexedDBに保存
- 画像は長辺1600pxにリサイズして容量を節約
- JSON形式でバックアップ・復元が可能

### 🌍 3D地球への観測点プロット
- 観測データを3D地球上にマーカーとして表示
- マーカークリックで詳細ポップアップ
- 「この地点へ飛ぶ」ボタンでカメラ移動
- カメラ距離に応じたLOD制御（遠距離では非表示）

### 📊 CSVエクスポート
- 期間指定でフィルタリング
- BOM付きUTF-8で出力（Excelで文字化け防止）
- PapaParseライブラリを使用

### ⚙️ 設定
- Pl@ntNet APIキーの管理
- iNaturalist利用のON/OFF
- JSONバックアップ/復元
- 全データ削除（2段階確認）

### 📶 オフライン対応
- AI判定失敗時は保留状態で保存
- オンライン復帰時に自動リトライ
- 保留中アイテムは🔄アイコンで表示

## セットアップ

### 1. 基本的な使い方（APIキー不要）
1. `fielddata/index.html` をブラウザで開く
2. 📸ボタンをクリックして写真をアップロード
3. 手動入力で種名・カテゴリを登録
4. 3D地球上にマーカーが表示されます

### 2. AI種同定を使う場合

#### Pl@ntNet APIキーの取得
1. [my.plantnet.org](https://my.plantnet.org/) にアクセス
2. アカウントを作成（無料）
3. ダッシュボードからAPIキーをコピー
4. ForestScopeの⚙️設定画面でAPIキーを入力

#### iNaturalist
- APIキー不要で利用可能（デフォルトON）
- レート制限あり

---

## プライバシー

- 写真と位置情報はすべてブラウザ内（IndexedDB）にのみ保存
- 外部に送信されるのはAI種同定APIへの画像送信時のみ
- 判定APIを使わない場合は完全にローカルで動作

## 技術仕様

- **Three.js v0.162.0** — 3D地球レンダリング
- **CSS2DRenderer** — マーカー表示
- **exifr v7.1.3** — EXIF GPS抽出
- **idb v8** — IndexedDBラッパー
- **PapaParse v5.4.1** — CSV生成
- ビルドステップなし — すべてCDN経由
